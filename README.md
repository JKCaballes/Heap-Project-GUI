Heap Project
Description

This project is a collection of Java programs created to demonstrate the concepts, operations, and applications of Heap Data Structures.

The project explores how heaps organize and manage data based on priority. It includes implementations and examples that demonstrate important heap concepts such as Min-Heaps, Max-Heaps, insertion, deletion, priority queues, and heap operations.

Objectives

The main objectives of this project are to:

Understand the concept and structure of a Heap.
Demonstrate the difference between Min-Heaps and Max-Heaps.
Implement common Heap operations.
Understand how elements are inserted and removed from a Heap.
Demonstrate the use of Priority Queues.
Apply Heap concepts to practical programming examples.
Develop Java programs using data structures and object-oriented programming.
